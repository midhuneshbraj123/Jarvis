Jarvis Slack Bot

Jarvis is a simple Slack bot created for the Stardance Challenge that provides useful utility commands and fun facts directly inside Slack.

Usage

Use these slash commands in any Slack channel where Jarvis is added:

/jarvis-ping – Check if the bot is online and view response latency.

/jarvis-help – Display the list of available commands.

/jarvis-catfact – Fetch and display a random cat fact.

/jarvis-joke – Fetch and display a random setup-and-punchline joke.
